# Reviewer Memory Test

## Most likely remembered sentence (current draft)

"The paper introduces reachability/morphology descriptors to analyze threshold behavior under imbalance."

## Sentence we want remembered

"Under severe imbalance, models with similar ranking and calibration summaries can behave very differently in threshold-mediated minority accessibility, so trajectory-aware evaluation is operationally necessary."

## Are they aligned?

- **Partially aligned**, but not fully.

## Why misalignment can occur

- Descriptor vocabulary (morphology/persistence/smoothness) is memorable and can overshadow the empirical non-equivalence phenomenon.
- Repeated caveat/framework language can compete with headline evidence in reader memory.

## How to improve alignment

1. Start and end each major evidence section with a direct non-equivalence sentence.
2. Keep running example (Bagged HDDT vs LightGBM) prominent as memory anchor.
3. Treat descriptor language as interpretive support, not primary takeaway.
4. Keep conclusion first paragraph explicitly phenomenon-first.
